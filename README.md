# Personal Portfolio

A modern, responsive developer portfolio built to showcase my skills, projects, experience, and journey as a Software Engineer.

## 🚀 Tech Stack

- **Frontend:** React.js, Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **AI Integration:** Groq API, Python, FastAPI

## ✨ Features

- Responsive and modern UI
- About, Skills, Projects, Experience, and Education sections
- Smooth animations and transitions
- Dedicated projects page
- **Jix** – AI-powered portfolio assistant that answers questions about my background, skills, and projects
